# Paradise Nursery - e-plantShopping

A React-based e-commerce web application for Paradise Nursery where users can browse indoor and outdoor plants, filter by categories, and manage items in an interactive shopping cart powered by Redux Toolkit.

## Features
- **Landing Page:** Interactive splash page with company mission.
- **Product Catalog:** Air purifying, aromatic, and low-maintenance plant listings.
- **Shopping Cart:** Add/remove plants and dynamically update item quantities with Redux state management.

## Tech Stack
- React
- Redux Toolkit & React-Redux
- Vite
